  魔方小将 · 小白三步安装详解
  （每一步都写清楚：点哪里、填什么、怎样算成功）
═══════════════════════════════════════════

【为什么需要三步，而不是直接装？】
苹果规定：iPad 上的应用必须用"苹果电脑"编译打包，
您的 Windows 电脑做不了最后一步。所以流程是：
  第①步  把程序"图纸"传到 GitHub（代码仓库）
  第②步  GitHub 用云端苹果电脑自动编译成安装包（.ipa）
  第③步  把安装包灌进 iPad
三步都只用做一次（之后更新才需要重复，见文末）。

【开做之前，先备齐这 5 样】
1. 您正在用的这台 Windows 电脑
2. 一根 iPad 数据线
   ※ 要能传数据的线。有些线只能充电。
     判断方法：插上后 iPad 弹出"信任此电脑？"就是好线
3. 一个苹果账号（Apple ID）
   ※ iPad 上登录的那个就行，免费账号就可用，不用花钱
4. 记得 iPad 的开机密码（中途要输）
5. 留出约 40 分钟

═══════════════════════════════════════════
第①步  把工程传到 GitHub（约 10 分钟）
═══════════════════════════════════════════
目标：把电脑里准备好的工程文件夹，传到网上代码仓库。

① 注册 GitHub 账号
  · 浏览器打开  https://github.com
  · 点右上角 "Sign up"，按提示用邮箱注册
  · 邮箱里会收到验证信，点链接激活
  （已有账号直接登录，跳到下一步）

② 下载 GitHub Desktop（Windows 版）
  · 浏览器打开  https://desktop.github.com
  · 点 "Download for Windows"
  · 下载完双击安装（一路下一步，全默认）

③ 打开 GitHub Desktop 并登录
  · 第一次打开会要求登录
  · 点 "Sign in to GitHub.com"，会自动跳浏览器
  · 浏览器里点授权，回来就登上了

④ 添加本地仓库（把工程文件夹交给它）
  · 点左上角菜单：File（文件）→ Add local repository
    （中文界面：文件 → 添加本地仓库）
  · 点 "Choose..."（选择）按钮，找到这个文件夹：
      D:\.workbuddy\三阶魔方速拧\cfop-app
  · 选好后点 "Add"（添加）
  ※ 它会自动识别出里面已有的提交记录，直接添加即可，
    不需要重新初始化

⑤ 发布到网上
  · 点上方工具栏的 "Publish repository"（发布仓库）
  · Name（名称）填：  mofang-app
  · "Keep this code private"（保持私有）这一项：
      建议取消勾选（公开仓库，云端编译不限次数）
      想保密就保持勾选，免费额度也够用（约 20 次/月）
  · 点 "Publish repository" 按钮
  · 等几十秒，按钮变成 "Fetch origin" 之类，就传完了
    （工程只有约 1MB，很快）

✔ 第①步成功标志：
  GitHub Desktop 菜单 Repository → View on GitHub
  能打开网页，看到一堆文件和文件夹（ios、src 等）

常见问题：
  · 选文件夹时提示"不是 git 仓库"？→ 文件夹路径选错了，
    必须是 D:\.workbuddy\三阶魔方速拧\cfop-app
  · 登录没反应？→ 用"浏览器登录"方式，不要手动输 token

═══════════════════════════════════════════
第②步  云端自动编译，下载安装包（约 10 分钟）
═══════════════════════════════════════════
目标：等云端工厂把工程编译成 iPad 能装的 .ipa 文件。
这一步是全自动的，您只要等和下载。

① 上传成功后，浏览器打开：
   https://github.com/<您的用户名>/mofang-app/actions
   ※ <您的用户名> 就是注册 GitHub 时起的名字
     （第①步 "View on GitHub" 打开网页，地址栏里能看到）

② 页面上能看到一条记录：
   "构建 iOS 安装包"
   · 黄点转动 = 正在编译（约 5~12 分钟）
   · 这时可以关掉网页去忙别的，编译完 GitHub 会给您发邮件
   ※ 它是在云端苹果电脑上编译整个工程，慢是正常的

③ 等记录变成绿色对勾 ✔，点这条记录进去

④ 页面拉到最下面，找到 "Artifacts"（构建产物）区域
   → 里面有：魔方小将-ipa
   → 点它下载（一个 zip 压缩包，约几百 KB）

⑤ 在下载文件夹里找到这个 zip，右键 → 解压到桌面
   → 得到文件：  App.ipa   ← 这就是安装包

⑥ 把 App.ipa 放到好找的位置（比如桌面），第③步要用

✔ 第②步成功标志：桌面上有 App.ipa 文件

常见问题：
  · Actions 页面空白/没有记录 → 第①步没上传成功，
    回第①步⑤确认 Publish 完成
  · 记录是红叉（失败）→ 点进去，展开报错的那个步骤，
    把红色日志截图发给我，我来修
  · Artifacts 只保留 14 天，过期会被删掉 →
    Actions 页面 → 左侧 "构建 iOS 安装包" → 右上角
    "Run workflow" 手动再跑一次，重新下载即可

═══════════════════════════════════════════
第③步  装进 iPad（约 15 分钟，只做一次）
═══════════════════════════════════════════
目标：用 Sideloadly 把 App.ipa 安装到 iPad 上。
这一步最容易在小地方卡住，请按顺序做，每步都有 ✔ 标志。

① 下载安装 Sideloadly（免费）
  · 浏览器打开  https://sideloadly.io
  · 点 "Download — Windows 64-bit"（绝大多数电脑选这个）
  · 下载完双击安装

② 装 iTunes 和 iCloud ★这一步装错，后面全卡★
   Sideloadly 靠 iTunes 的驱动才能认出 iPad，
   而且必须是【苹果官网版本】：
   · 先检查有没有装过微软商店版：
     设置 → 应用 → 已安装的应用 → 搜 "iTunes"、"iCloud"
     如果有，先卸载（微软商店版 Sideloadly 连不上）
   · 从苹果官网下载安装（复制到浏览器打开）：
     iTunes 64 位：https://www.apple.com/itunes/download/win64
     iCloud for Windows：
     https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe
   · 装完后【重启电脑】（让苹果的设备驱动生效）

③ 数据线连接 iPad
  · 用 USB 线把 iPad 连到电脑
  · iPad 屏幕弹出 "信任此电脑？" → 点 "信任" → 输入开机密码
  · 打开 iTunes，确认左上角能看到您的 iPad 图标
    ✔ 能看见 = 驱动正常，关掉 iTunes
    （看不见 → 换根线/换个 USB 口，回第②步检查驱动）

④ 在 Sideloadly 里设置并开始安装
  · 打开 Sideloadly
  · 上方 "iDevice" 栏应显示您的 iPad
  · 把 App.ipa 拖进左边 IPA 图标框里
  · "Apple ID" 栏填您的苹果账号
  · 建议勾选 "Automatic app refreshing"（自动续签，
    以后不用每周手动续，详见附录 A）
  · 点 "Start"（开始）

⑤ 账号验证（首次会出现）
  · 输入 Apple ID 密码
  · 如果开了双重认证：苹果会给您的其他苹果设备
    （iPhone/Mac）弹 6 位验证码 → 填进去
  · 如果提示要"专用密码"：
    浏览器打开 https://appleid.apple.com
    → 登录与安全 → 专用密码 → 生成新的专用密码
    → 复制那 16 位密码 → 粘到 Sideloadly 密码框

⑥ 等 1~2 分钟，Sideloadly 显示 "Installed"/"Done"
  ✔ 到这一步，App 已经进 iPad 了

⑦ iPad 上做两件事（不做的话打不开）
  a. 信任开发者：
     设置 → 通用 → VPN与设备管理 → 开发者 App
     → 点您的 Apple ID → 信任
     （旧系统路径：通用 → 描述文件与设备管理）
  b. 打开开发者模式（iOS 16 及以上系统必须）：
     设置 → 隐私与安全性 → 开发者模式 → 打开 → 重启
     → 重启后弹出询问 → 打开 → 输密码
     ※ 装过 App 后这一项才会出现
     ※ 找不到这一项 = 系统低于 iOS 16，跳过即可

⑧ 回主屏幕，点 "魔方小将" 图标
  · 第一次打开时，让 iPad 联网几秒钟
    （苹果要求新装的应用首次打开时验证一次签名证书，
     连一下 WiFi 或手机热点即可，几秒就完）
  · 之后拔掉网络，日常使用完全不需要联网

✔ 第③步成功标志：
  全屏界面（没有浏览器地址栏）、竖屏、
  各页面能正常点开、练习闯关都能玩

⑨（核心功能）连真魔方试一下：
  拧一下魔方白色面唤醒（白灯闪 3 下）→ 关掉官方
  CubeStation → App 底部 "🔵 GAN" 页 → 点 "连接魔方"
  → 拧真魔方，屏幕同步转动 = 大功告成
  （详细排障看《安装手册-iOS原生版.txt》第 5 步）

附录 A：每周续签，怎么做到不用管
═══════════════════════════════════════════
免费苹果账号的 App 7 天到期是苹果的规定，躲不掉。
但可以全自动：
· 第③步④勾了 "Automatic app refreshing" 的话，
  Sideloadly 的后台守护程序会在 App 快到期时自动续签
· 条件：电脑开机 + Sideloadly 装着；iPad 用 USB 连着电脑，
  或和电脑连同一个 WiFi
  （想用 WiFi 续签：iTunes → 设备 → 摘要 → 选项 →
    勾"通过 WiFi 与此 iPad 同步"→ 同步一次）
· 满足条件后它自己干活，您完全不用管
· 万一漏签（图标变灰）：把 iPad 连回电脑，
  打开 Sideloadly 点刷新即可，1 分钟，数据不丢
· 想一年都不管：加入苹果开发者计划 $99/年
  （Sideloadly 用付费账号签名，有效期 1 年）
