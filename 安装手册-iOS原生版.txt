【为什么必须用原生版】
App 的核心玩法是「连真魔方 → 拧一步屏幕转一步 → 自动计时」。
苹果禁止 iPhone/iPad 的浏览器使用网页蓝牙，所以 PWA（网页版）
在 iPad 上永远连不了魔方；原生 App 走系统蓝牙，可以连。
本工程已完整实现 GAN 魔方协议（Gen2/Gen3/Gen4，含 AES 解密）。

【方案总览】
App 已包装成标准 iOS 工程（Capacitor 6），放在：
  D:\.workbuddy\三阶魔方速拧\cfop-app
云端构建流水线已配好。您只需做 3 件事：

  ① 把工程传到 GitHub（用 GitHub Desktop，5 分钟）
  ② 云端自动构建出 .ipa 安装包，下载（约 10 分钟，全自动）
  ③ 用 Sideloadly 通过 USB 线装进 iPad（10 分钟）

之后 App 就是 iPad 上的原生应用，与电脑、网络全部无关。
免费苹果账号签名的应用有效期为 7 天，到期需重签一次（见第 6 步）；
要一年稳定有效需加入苹果开发者计划（$99/年，见第 7 步）。

───────────────────────────────────────────
第 1 步：把工程传到 GitHub
───────────────────────────────────────────
1. 浏览器打开 github.com，注册并登录账号
   （已有账号直接登录）

2. 下载安装 GitHub Desktop（Windows 版）：
   https://desktop.github.com

3. 打开 GitHub Desktop：
   File（文件）→ Add local repository（添加本地仓库）
   文件夹选择：  D:\.workbuddy\三阶魔方速拧\cfop-app
   （它会识别出已有的 git 提交记录，直接点添加）

4. 点上方 "Publish repository"（发布仓库）：
   · Name 填：mofang-app
   · 取消勾选 "Keep this code private"（公开仓库构建不限时长；
     如勾选私有，免费额度也够用约 20 次构建/月）
   · 点 Publish repository

   等几十秒，上传完成（工程约 1MB）。

───────────────────────────────────────────
第 2 步：云端自动构建，下载 .ipa
───────────────────────────────────────────
1. 上传完成后，浏览器打开：
   https://github.com/<你的用户名>/mofang-app/actions

2. 能看到一条 "构建 iOS 安装包" 的记录正在运行
   （黄点=进行中，约 5~12 分钟）

3. 变绿勾后点进去 → 页面下方 "Artifacts" 区域
   → 下载 "魔方小将-ipa"（一个 zip 压缩包）

4. 解压后得到：  App.ipa   ← 这就是安装包

   ※ 以后每次想更新 App：改代码 → GitHub Desktop 里 commit + push
     → 自动重新构建 → 下载新的 .ipa → 重装即可

───────────────────────────────────────────
第 3 步：安装到 iPad（USB 线，一次性）
───────────────────────────────────────────
1. 电脑下载安装 Sideloadly（Windows 版，免费）：
   https://sideloadly.io

2. 安装 iTunes 和 iCloud（重要！）：
   · 打开微软应用商店（Microsoft Store）
   · 搜索 "iTunes" → 安装（苹果官方版）
   · 搜索 "iCloud" → 安装
   ※ 必须是微软商店版，不要用苹果官网的老版桌面 iTunes

3. 用 USB 线把 iPad 连接到电脑
   · iPad 上弹出 "信任此电脑？" → 点 "信任"，输入密码

4. 打开 Sideloadly：
   · 把第 2 步下载的 App.ipa 拖进 Sideloadly 窗口
   · Apple ID 栏填您的苹果账号
   · Device 栏选择您的 iPad
   · 点 "Start"（开始）

5. 首次使用会要验证：
   · 苹果会给您的其他苹果设备发验证码 → 填入
   · 若提示生成 "专用密码"：浏览器打开
    appleid.apple.com → 登录与安全 → 专用密码 → 生成一个
    （复制这 16 位密码，粘贴到 Sideloadly 密码框）

6. 等待 1~2 分钟，提示 "Installed" 即成功

7. iPad 上信任开发者：
   设置 → 通用 → VPN与设备管理 → 开发者 App
   → 点您的 Apple ID → 信任
   （旧系统路径：设置 → 通用 → 描述文件与设备管理）

8. 回主屏幕，出现 "魔方小将" 图标，点开即用 ✔

───────────────────────────────────────────
第 4 步：验证安装
───────────────────────────────────────────
· 图标点开是全屏 App（没有浏览器地址栏）
· 竖屏锁定方向
· 练习、闯关、皮肤等全部功能可正常使用
· 拔掉 USB 线，关掉电脑 WiFi —— App 照常使用

───────────────────────────────────────────
第 5 步：连接 GAN 智能魔方（核心功能）
───────────────────────────────────────────
1. 唤醒魔方：拿起来拧一下白色面，白灯闪 3 下（睡着了连不上）
2. 确认没被别的 App 占用：手机/平板上如果开着官方
   CubeStation，先退掉（魔方同时只能连一个设备）
3. iPad 打开「魔方小将」→ 底部导航「🔵 GAN」页
   → 点「📡 连接魔方」
4. 首次会弹「需要魔方 MAC 地址」：
   · App 会先从蓝牙广播里自动读 MAC（多数情况直接过）
   · 读不到才需要手输一次：用另一台设备装 nRF Connect
     连上魔方即可看到；格式如 AB:12:34:00:27:97
   · 输一次后同一条魔方永远记住，不用再输
5. 连上后：拧真魔方 → 屏幕魔方同步转动 → 自动开始计时
6. 如果屏幕转的方向和手里对不上：
   → 点「🧭 校准方向」把 GAN 每一面对应到真实方向
   → 点「↺ 归零同步」让屏幕和真魔方重新对齐
7. 魔方没电/关机 → App 会提示断开，重新连即可

※ 支持 GAN356i / GAN12 / 13 / 14 / GAN Mini / MoYu AI
   等采用 GAN 协议的智能魔方；Giiker、奇艺等其他品牌不支持。

───────────────────────────────────────────
第 6 步：免费账号的 7 天续签（每周一次）
───────────────────────────────────────────
免费苹果账号签名的应用 7 天后图标会变灰、无法打开
（苹果官方限制，所有免费侧载工具一样）。续签方法：

1. iPad 用 USB 线连回这台电脑
2. 打开 Sideloadly（不用重新拖 IPA）
3. 左侧 "Installed Apps" 会出现该 App，点刷新按钮
4. 等 1 分钟，续签完成，再有效期 7 天

· 免费账号最多同时装 3 个侧载应用（我们只装 1 个，够用）
· 如果嫌每周续签麻烦 → 看第 7 步

───────────────────────────────────────────
常见问题
───────────────────────────────────────────
Q1：Actions 页面没有构建记录 / 构建失败
  → 确认上传成功（GitHub Desktop 显示 "Published"）
  → 仓库路径要对：github.com/<用户名>/mofang-app
  → 点进失败记录看红字日志，把日志发我，我来修

Q2：Sideloadly 提示 "iTunes not found"
  → 第 3 步第 2 条没做：去微软商店装 iTunes + iCloud

Q3：Sideloadly 提示错误代码 / 无法连接
  → 换一根 USB 线（有些线只能充电不能传数据）
  → 换 USB 口（直插主机，不要用劣质扩展坞）
  → iPad 上重新 "信任此电脑"
  → 电脑不要同时开其他占用 iTunes 的软件

Q4：App 装上了但打开闪退
  → 第 3 步第 7 条没做：去设置里 "信任" 开发者

Q5：7 天后 App 打不开（图标灰色）
  → 正常现象，按第 6 步续签即可

Q6：进度会丢吗
  → 不会。进度存在 iPad 本地。续签、重装同名 App
    都不会丢数据；只有删除 App 才会清空

Q7：连不上魔方 / 拧了屏幕不动
  → 先拧白面唤醒（白灯闪 3 下），魔方拿近一点
  → 关掉官方 CubeStation（魔方同时只能连一个设备）
  → MAC 输错也会解出乱码：App 记住的 MAC 不对时，
    清掉重来：GAN 页 → 连接魔方 → 弹窗里重新输入
  → 用「🧪 模拟一步」按钮可先确认程序本身正常
    （拧了模拟步屏幕魔方会动，说明链路没问题）

Q8：换了别的 GAN 魔方
  → 直接连，App 会自动适配（Gen2/Gen3/Gen4 都支持）
  → 若方向对不上，用「🧭 校准方向」
