🔧 校准与归零

不同固件上报的"面序号"可能不一样。连上后如果屏幕上转的方向和手里的对不上，先点「校准方向」把 GAN 的每一面重新对应到你魔方的真实方向，再「归零」让屏幕和真魔方同步。

✅ 支持情况（很重要）

iPad / iPhone浏览器的网页蓝牙被苹果禁止，但原生 App 版「魔方小将」可以直接连魔方——用随附说明安装到主屏幕的 App 就是原生版，打开本页点「连接魔方」即可。
安卓 / 电脑用 Chrome 或 Edge 打开本程序，即可直接连魔方。
小提示连接前先拧一下白色面唤醒魔方（白灯闪 3 下）；电脑上用 http:// 打开（用附带的启动器），直接双击文件时浏览器会禁用蓝牙。

🔧 连不上怎么办

1. 先拧一下白色面唤醒魔方（白灯闪 3 下），电量要足
2. 蓝牙已打开，且魔方没被 CubeStation 占用（先关掉那个 App）
3. 电脑上要用 Chrome / Edge，且地址是 http:// 开头
4. 还是不行 → 先用"模拟一步"确认程序本身正常

🎨 皮肤小屋

魔方皮肤只换特效，六个面的基础颜色永远保持经典六色，照样认色、照样复原；玩伴可以随便换，全部免费。

📲 安装到 iPad

装到桌面后，它就像普通 App 一样：全屏、有图标、断网也能用。

方法一：添加到主屏幕（推荐，1 分钟）

① 起服务在电脑上双击 启动服务器.bat，记下窗口里显示的地址（形如 http://192.168.x.x:8080）。
② 同一 WiFi让 iPad 连上和电脑同一个 WiFi。
③ 打开在 iPad 的 Safari 里输入那个地址。
④ 安装点右上角 分享 ⤴ → 往下找 「添加到主屏幕」 → 添加。
⑤ 完成桌面会出现「魔方小将」图标。以后点图标直接全屏打开，不需要再开电脑（首次加载后已离线缓存）。

方法二：打包成真正的 .ipa（进阶）

如果一定要装成 App Store / TestFlight 那种原生包，需要用 Capacitor 把本项目套壳，再用 Xcode（必须 macOS）签名导出。
项目里已放好 capacitor.config.json，在 Mac 上依次执行：
npm i @capacitor/core @capacitor/cli @capacitor/ios
npx cap init 魔方小将 com.mofang.cfop --web-dir=.
npx cap add ios
npx cap open ios  # 在 Xcode 里选你的 iPad 运行
这条路必须有 Mac + Apple 开发者账号（免费账号也能自签 7 天）。没有 Mac 的话，方法一完全够用，体验几乎一样。
